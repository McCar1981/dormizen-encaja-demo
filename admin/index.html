DESARROLLO A MEDIDA

Tienda, backend y administrador propios. El sistema gestionará catálogo, variantes, precios, pedidos, promociones y acceso autenticado por roles, con reglas de fabricación y entrega por código postal. Los datos se almacenarán en una base de datos y se validarán en el servidor. Plazo de entrega del proyecto: 4–5 semanas desde el inicio acordado.
