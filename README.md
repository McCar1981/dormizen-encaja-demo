# DormiZen Encaja · demo conceptual

Propuesta independiente de tienda online para presentar a DormiZen. No es la tienda oficial y no realiza pedidos.

- Seis productos, precios, plazos, reglas de fabricación y tarifas de transporte son **ejemplos ficticios**.
- El configurador comprueba medidas, un paso mínimo y códigos postales peninsulares mediante reglas de muestra.
- El carrito y la confirmación funcionan solo en la memoria del navegador. No se recogen datos personales ni se procesan pagos.
- La vista 3D y el asesor son simulaciones identificadas dentro de la interfaz; no hay modelos 3D reales ni IA conectada.

## Abrir

Abrir index.html en un navegador moderno, o publicar la carpeta completa en GitHub Pages conservando assets/, style.css y app.js junto a index.html. Las rutas son relativas y no requieren instalación ni compilación.
