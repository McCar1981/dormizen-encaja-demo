# DormiZen Encaja · demo conceptual

Propuesta independiente de tienda online para presentar a DormiZen. **No es la tienda oficial y no realiza pedidos.**

- Seis nombres de producto, fichas, opciones, precios, plazos, reglas de fabricación y tarifas de transporte son **ejemplos ficticios**. Las fotos reales de las tarjetas solo ilustran las categorías; no representan esos artículos ni sus precios.
- El configurador comprueba medidas, un paso mínimo y códigos postales peninsulares mediante reglas de muestra.
- El carrito y la confirmación funcionan solo en la memoria del navegador. No se recogen datos personales ni se procesan pagos.
- La vista 3D y el asesor son simulaciones identificadas en la interfaz; no hay modelos 3D reales ni IA conectada.
- El logo y seis fotografías de referencia provienen de dormizen.com; la imagen de portada se generó para este prototipo. Véase ASSETS.md para URL y atribución exactas. **Antes de usar estas fotos en una tienda comercial real, hay que confirmar con DormiZen y con los posibles fotógrafos o proveedores los derechos de uso.**

## Abrir

Abrir index.html en un navegador moderno, o publicar la carpeta completa en GitHub Pages conservando assets/, style.css, brand.css y app.js junto a index.html. Las rutas son relativas y no requieren instalación ni compilación.
